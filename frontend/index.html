📖 Forensic Architecture & Scientific Standards

Implemented based on published digital forensics triage principles and the StegoForge detection specification.

1. Level 1 — File Triage & Cryptographic Preservation

Every submitted file is hashed with SHA-256, MD5, and SHA-1 for chain of custody. The system inspects file magic headers (e.g., \x89PNG, \xFF\xD8\xFF, %PDF, PK\x03\x04) and flags extension disguise attempts (e.g., an executable renamed to .jpg).

2. Level 2 — Format-Specific Steganography Screening

  • Chi-Square ($\chi^2$) Analysis: Evaluates Pairs of Values (PoVs $2k, 2k+1$) across pixel luminance distributions. LSB substitution equalizes natural frequencies; p-value drops below $0.05$.
  • RS Steganalysis (Fridrich et al.): Samples pixel vectors under dual flipping masks $M$ and $-M$. Measures Regular ($R$) and Singular ($S$) group behavior to estimate payload percentage.
  • Container Overlay Verification: Scans for bytes appended past standard markers (JPEG FF D9, PNG IEND, PE Section Header table).
  • Unicode Zero-Width Detector: Detects and reconstructs covert binary payloads hidden using \u200B and \u200C invisible code points.
  • Error Level Analysis (ELA): Generates amplified compression discrepancy maps to visually reveal manipulation.

3. Level 3 — Forensic Correlation & Scoring

Consolidates independent evidence sources. A score between 0 and 100 categorizes evidence into Clean, Low Risk, Suspicious, or High Suspicion, ensuring false-positive safeguards.

⚠️ Responsible Use & Evidentiary Boundaries

This tool serves as an investigative screening aid to prioritize files for deeper review. The presence of an anomaly is not definitive proof of malicious tampering, and the absence of flags does not guarantee absolute authenticity. Final conclusions require qualified examiner verification.
